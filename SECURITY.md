# Security

If you believe you have found a security vulnerability in this repository or the zkde.fi deployment, please report it responsibly.

**Do not** open a public GitHub issue for undisclosed vulnerabilities.

Contact **Obsqra Labs** through a private channel you already use for the project, or reach out via the security contact published on [obsqra.xyz](https://obsqra.xyz) if available.

Include:

- A short description of the issue and its impact
- Steps to reproduce (or a proof-of-concept) where safe
- Affected components (e.g. `backend/`, `frontend/`, specific contracts)

We will acknowledge receipt and coordinate disclosure and fixes as appropriate.
