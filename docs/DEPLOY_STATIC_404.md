# Fixing 404 on /_next/static (CSS/JS chunks)

When the app returns **404** for `/_next/static/css/*.css` or `/_next/static/chunks/*.js`, the HTML was generated by one build but the chunk filenames on disk are from another (e.g. new deploy, or cached HTML).

**Fix (on the server that hosts zkde.fi):**

1. Run the script:
   ```bash
   ./scripts/fix-static-404.sh
   ```
   This rebuilds the frontend, restarts the Node process (PM2), and reloads nginx.

2. Purge any CDN cache (e.g. Cloudflare “Purge Everything”) for zkde.fi.

3. Hard-refresh the browser (Ctrl+Shift+R / Cmd+Shift+R) or use an incognito window.

Nginx is already configured to proxy `/_next/static/` to the Next.js app and to avoid caching HTML for `/`. The critical step is ensuring the running Node process serves the **same** build that produced the HTML the user receives.
