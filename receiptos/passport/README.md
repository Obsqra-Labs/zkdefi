# Passport (v0.1)

This folder is reserved for the ReceiptOS passport frontend.

Recommended path for pilot:
- Build as isolated Next.js app in this folder first.
- Integrate into `zkde.fi/passport` only after Sepolia E2E claim passes.

Required pages/features:
- Wallet connect (Argent/Braavos)
- Vector display for six signals
- Claim flow showing receipt id and tx hash
