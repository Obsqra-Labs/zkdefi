# Introduction

zkde.fi is a privacy-first execution stack on Starknet with two operator surfaces:

- [Capital OS](/capital-os) (`/agent`) for trust posture, policy, and orchestration.
- [Trade Desk](/trade-desk) (`/trade`) for opportunities, adapters, simulation, and execution.

## What This Docs Set Focuses On

1. How to use the product end-to-end.
2. Where adapters and opportunities are surfaced.
3. How policy, proofs, and settlement work in production.
4. Which APIs and components back each workflow.

## Core Routes

- `/profile`: identity, trust/reputation, and disclosure state.
- `/agent`: Capital OS operations and orchestration controls.
- `/trade`: Trade Desk execution workflow.
